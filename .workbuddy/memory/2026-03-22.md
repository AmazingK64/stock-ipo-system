2. **`src/components/RealTimeMarginData.tsx`**：`useEffect` 改为空函数，移除自动请求和定时器，等用户手动点击刷新

## 2026-03-22 00:36 - AIWorkflow组件属性名不匹配修复

### 问题
报错：`Cannot read properties of undefined (reading 'stockName')`

### 原因分析
`IPOList.tsx` 中调用 `AIWorkflow` 组件时使用了错误的属性名 `record`，而组件期望的是 `ipoData`。这导致 `ipoData` 为 `undefined`，当组件尝试访问 `ipoData.stockName` 时报错。

### 解决方案
1. **修复属性名**：`record` → `ipoData`
2. **修正函数名大小写**：`setAiWorkflowVisible` → `setAIWorkflowVisible`
3. **增强组件健壮性**：修改 `AIWorkflow` 组件接口，支持 `null/undefined` 数据，并添加空状态处理

### 修改文件
1. `/src/components/IPOList.tsx`:
   - 第153行：`record={selectedIPO}` → `ipoData={selectedIPO!}`
   - 第154行：`setAiWorkflowVisible` → `setAIWorkflowVisible`

2. `/src/components/AIWorkflow.tsx`:
   - 修改接口定义：`ipoData: IPOStock` → `ipoData: IPOStock | null | undefined`
   - 添加空数据状态处理：当 `ipoData` 不存在时显示警告提示

### 验证结果
- TypeScript编译检查通过
- 无新的lint错误

### 经验总结
- 组件接口定义要和实际调用保持一致
- 对于可能为空的 props，使用联合类型 `Type | null | undefined`
- 添加空状态处理可以提升用户体验，避免白屏或报错
